# Item 2 — 三階jetと `J = F_rr/r` の一様負性

日付: 2026-07-26
状態: **参照実装と探索結果（float64）。認証ではありません。**

## 代数：除算を消す

`E` は `r` の偶関数なので `E = Psi(s)`, `s = r^2` と書けます。すると

    F     = E_r   = 2 r Psi_s
    F_r   = E_rr  = 2 Psi_s + 4 s Psi_ss
    F_rr  = E_rrr = r ( 12 Psi_ss + 8 s Psi_sss )

したがって

    J(r,a) := F_rr / r = 12 Psi_ss + 8 s Psi_sss

となり、`r` による除算が完全に消えます。`Phi = 2 Psi_s` と置けば
`J = 2(3 Phi_s + 2 s Phi_ss)` で、ご提示の式と一致します。連続延長は

    J(0,a) = 12 Psi_ss(0,a) = H_4(a)

です（`F = Q r + H_4 r^3/6 + O(r^5)` から `Psi_s = Q/2 + H_4 s/12 + ...`）。

被積分関数レベルでは `s` の関数になるのは `phi` と `phi+pi` を対にした
対称化後です。`v = r u` と置くと

    W_hat = [ (1-v) h(x_+) + (1+v) h(x_-) ] / 2,
    x_pm  = C (1 -+ v) / sqrt(1 -+ 2v/ell + s/ell)

は `v` について偶で、`v^2 = s u^2` なので `s` のみの関数です。

## jet仕様

階乗正規化 `X^[k] = (1/k!) d^k X / dr^k`, `k = 0..3`。積は畳み込み
`(XY)^[n] = sum_k X^[k] Y^[n-k]`。合成は

    Z^[0] = f(P0)
    Z^[1] = f' P1
    Z^[2] = f' P2 + (f''/2) P1^2
    Z^[3] = f' P3 + f'' P1 P2 + (f'''/6) P1^3

`P^alpha` はこの合成に `f = p^alpha` を入れて生成します。角度関数は
`h, h', h'', h'''` が必要で、`0F1` 形

    S = 0F1(3/2; -beta^2/4),  T = 0F1(5/2; ...),  U = 0F1(7/2; ...)
    h1 = -2/S
    h2 = (2/3) T / S^3
    h3 = (2/15) U / S^4 - (2/3) T^2 / S^5

を使えば `beta -> 0` でも相殺を失いません。

## 検証（`item2_jet3.py`）

1. `F_r(0,a) = Q(a)` を認証済みCAP値と照合：4点すべて **4e-15** 以内
2. jetの `F_rr` と `F_r` の中心差分：相対差 `1e-8`（差分側の打ち切り誤差
   のオーダー、`r=0.9` で `2e-7`）
3. `J(r,a) -> H_4(a)`：`r = 0.2, 0.05, 0.01, 0.002` で単調に収束
   （`a=4.72438` で `-1.454264, -1.439449, -1.438524, -1.438487`）

## 拡大閉領域上の `sup J`

    R = [206538/100000, 472439/100000] x [0, 1]

1360点の走査で

    sup_R J = -1.438484    at  a = 472439/100000,  r -> 0

`J` は `r` について単調減少、`a` について単調増加なので、上限は角
`(a_max, r=0)` にあり、そこでの値は `H_4(a_max)` に一致します。

| a | `H_4(a) = J(0,a)` |
|---|---|
| 2.06538 | `-3.272640` |
| 3.0 | `-2.285933` |
| 4.0 | `-1.706774` |
| 4.7 | `-1.446164` |
| 4.72439 | `-1.438483` |

`a = 4.72439` 固定での `r` 依存：

| r | 0.001 | 0.05 | 0.2 | 0.5 | 0.8 | 0.999 |
|---|---|---|---|---|---|---|
| J | `-1.4385` | `-1.4394` | `-1.4543` | `-1.5528` | `-1.8755` | `-4.8564` |

したがって有理上界として

    J(r,a) < -7/5    on R

が狙えます（sup までの余裕 0.038、約2.7%）。符号の小ささは問題ではなく、
難所はパラメータballの依存性だけです。適応的箱分割（失敗箱のみ二分）が
適します。

## 残る二つの大域符号

`J < 0` の後に必要な `Q > 0` と `B < 0` について、探索した結果、
**両者のタイトな端は既に認証済みの点と一致します**。

| 命題 | 範囲 | 最悪値 | 位置 | 現状 |
|---|---|---|---|---|
| `B(a) < 0` | `[2.06539, 4.72439]` | `-1.687e-6` | 左端 `a=2.06539` | **認証済み** |
| `Q(a) > 0` | `[2.06538, 4.72438]` | `+3.222e-7` | 右端 `a=4.72438` | **認証済み（CAP）** |

内部の余裕は桁違いです（`B(4.72439) = -0.2707`、`Q(2.06538)` は
`3.3e-3` 程度）。したがって大域化は次のどちらかで閉じます。

- 各 `a`-セルで直接認証する（仮定が少なく堅実）
- 単調性 `B_a < 0`、`Q' < 0` を全域認証し、端点値に帰着させる

現在認証済みの `B'([2.06538, 2.06539]) < 0` と CAP の
`Q'(a) < 0 on [4.7, 4.75]` は、いずれも端の近傍だけの結果である点に
注意が必要です。それだけでは全域は従いません。

## SymPy監査で確認すべき等式

    F_r^{jet}  == F_r^{symbolic}
    F_rr^{jet} == F_rr^{symbolic}
    F_rr       == r * J
    J(0,a)     == H_4(a)

`simplify` が重い場合は、差を共通分母にまとめて分子を `factor` または
`cancel` でゼロ確認する方が安定します。数値代入は監査の代用にせず、
補助試験として別に残してください。

## 区間計算の分割案

- `r in [0, r_0]`：`J` の因数分解形（`s` 形式）を使用
- `r in [r_0, 1]`：同じ `J` 形、または `F_rr < 0` を直接
- `r = 1` の接触点：境界侵入で確立した `t, N, K` 形式で処理
- `a`：幅が崩れたセルのみ二分
