## 結論

`F_rr(r,a) < 0` は探索領域全体で成立しました。転回点枝の追跡は不要です。

さらに強く、`F_rr` は `r=0` で線形に消えるだけなので、正しい一様命題は

    F_rr(r,a) / r  <=  -1.4384        for (a,r) in (lambda_partial, a_c) x (0,1)

です。上限は `a -> a_c`, `r -> 0` の角で達成され、そこでの値は
`H_4(a_c)` に一致します。margin は約 1.44 で、ゼロ近傍ではありません。

## 証明の縮約

`F_rr < 0` が認証できれば、項目2の中心命題は次の三点だけになります。

1. `F_rr(r,a) < 0` on `(lambda_partial, a_c) x (0,1)`
   → `F_r(.,a)` は `r` について狭義単調減少
2. `F_r(0,a) = Q(a) > 0` for `a < a_c`
   → CAPの `Q` カーネルをそのまま使える。`Q(a_c)=0`, `Q'(a_c)<0` は認証済み
3. `F(1,a) < 0` for `a > lambda_partial`
   → `B(a) = F(1,a)` の認証済み結果と `B' < 0` から従う

1と2から `F_r` は `(0,1)` でちょうど一度符号を変え、`F` は単峰。
`F(0,a) = 0` と3を合わせると、非零停留根 `r_*(a)` はちょうど一つ。

転回点枝 `F_r = 0` の管認証、三領域分割、`a_c` 端の `y = r^2/(a_c-a)`
スケーリングは、いずれも不要になります。

## 実装上の注意

`F_rr` は `E` の三階 `r` 微分です。旧 `(theta,phi)` 形式を直接三回
微分するのではなく、境界侵入の認証で使った正則形

    t = sin(chi/2),  m = 1-u = 2t^2,  N = 4t^2 A,  K = 4t^2 (1-t^2) J

を保ったまま、`r` についての三階jetで生成すべきです。一般の `r` では
接触点は消えますが、`r -> 1` で再び鋭くなるためです。

手入力の展開式は避け、前進自動微分で生成した上で、

    F_r^{jet}  == F_r^{symbolic}
    F_rr^{jet} == F_rr^{symbolic}

のSymPy監査を別途置くのが安全です。
